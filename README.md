# developofsredstvaofdefensinformation_encript_and_decript_repozitory

=======================================================

ПОСТАНОВКА ЗАДАЧИ:

Реализовать защиту данных пользовательских папок и файлов находящихся в папке, а также подпапках путем шифрования. Для доступа к данным исходной папке дешифрование.

  1 Интерфейс на выбор - консоль, либо реализация с помощью
визуального интерфейса (Qt widgets, WinForms).
  2 В качестве основной библиотеки для реализации шифрования
можно взять библиотеку Crypto++ Library, либо Aes256
https://codezup.com/cryptography-security-in-cpp-applications/
https://codezup.com/cpp-aes-256-encryption-implementation/
  3 Потребуется реализация рекурсивного обхода папок, с целью
шифрования всех вложенных файлов.

Для реализации этой задачи можно воспользоваться
библиотеками
    а) dirent.h
https://github.com/tronkko/dirent
    б) Библиотеками QT( предпочтительно. )
Представляет богатый инструментарий по работе с директориями и файла.
Например - https://pro-prof.com/forums/topic/%D0%BE%D0%B1%D1%85%D0%BE%D0%B4-%D0%B4%D0%B5%D1%80%D0%B5%D0%B2%D0%B0-%D0%BA%D0%B0%D1%82%D0%B0%D0%BB%D0%BE%D0%B3%D0%BE%D0%B2-c-qt


Требование к реализации
  1 Язык с++
  2 Реализовать основной класс, обеспечивающий шифрование(encryption), дешифрование (decryption) как Singleton.
  3 Входные данные путь к папке для шифрования/дешифрования, пароль для шифрования

========================================================

ОПИСАНИЕ ИСПОЛЬЗУЕМОГО ИНСТРУМЕНТАРИЯ:

1)язык программирования - с++
2)система сборки - CMake (помогает прописать зависимости и параметры сборки проекта)
3)паттерн <Одиночка> - задает правила использования член данного (можно создать только один в процессе жизни программы, это контролируется параметром static), ограничивает использование конструкторов (переносим в приват зону)
4)алгоритм шифрования - ChaCha20 (найден в интернете алгоритм и его реализация) - современный симметричный потоковый алгоритм шифрования (2008г) тут почитать - https://loup-vaillant.fr/tutorials/chacha20-design, тут есть гитхаб алгоритма на с++ - https://github.com/983/ChaCha20/tree/master
5)#include <filesystem> - работа с файлами, имеет метод recursive_directory_iterator(folder)) - позволяет итеративно обойти директорию
